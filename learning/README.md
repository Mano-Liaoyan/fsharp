# Learn F# from the beginning

Start with [Lesson 01: your first script](lessons/0001-your-first-script.html).
Open the HTML file in a browser. It explains every part of a two-line program
and tells you exactly what to edit and run.

You need zero F# experience. The required .NET tools are already installed.

## Today's files

- [Example to run](exercises/0001-first-script/demo.fsx)
- [Small exercise to edit](exercises/0001-first-script/practice.fsx)
- [Reference for this lesson](reference/fsharp-basics.html)

In PowerShell, run:

```powershell
cd C:\dev\fsharp
dotnet fsi learning/exercises/0001-first-script/demo.fsx
```

The example prints `Sam`. Follow the lesson before editing the practice file.
