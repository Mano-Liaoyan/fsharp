# Mission: Build a business application in F#

## Why
Model and implement a real business application in F# using the approach taught
in Scott Wlaschin's *Domain Modeling Made Functional*. Use this repository to
turn business requirements into working code and learn how to adapt that code
as the requirements change.

## Success looks like
- Discover and document a workflow's vocabulary, boundaries, and business rules.
- Represent allowed data and states with F# types and validate incoming data.
- Implement a complete workflow with explicit errors and external dependencies.
- Connect the model to serialization and persistence, then add a new requirement.
- Apply the approach to a second business domain and explain the tradeoffs.

## Constraints
- Experienced programmer with zero F# experience; start with basic F# syntax
  and small runnable scripts, explaining each new symbol before using it.
- Learn and practice in this repository; .NET and F# Interactive are installed.
- The eventual application domain, study time, and book access are not yet specified.

## Out of scope
No additional exclusions specified by the learner.
