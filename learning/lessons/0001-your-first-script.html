Lesson 01 · Start from zero F#

Run two lines.
Understand both.

About 10 minutes · No previous F# knowledge needed

Our eventual goal is a business application. Today, we will give a customer's name to the computer and display it. That is the whole exercise.

1. Run your first script

F# is pronounced F sharp. A file ending in .fsx is an F# script: a text file containing F# code that we can run directly.

Open demo.fsx in your code editor. It contains exactly these two lines:

F# code — this goes in the .fsx file

let customerName = "Sam"
printfn "%s" customerName

Open a PowerShell terminal. Paste these commands there:

Terminal commands — run these in PowerShell

cd C:\dev\fsharp
dotnet fsi learning/exercises/0001-first-script/demo.fsx

cd selects the project folder. dotnet fsi starts the F# script runner; the path after it selects our file. The required tools are already installed on this machine. Microsoft's script-running reference.

Expected terminal output

Sam

If you see Sam, you have run your first F# program.

2. Read the first line

let customerName = "Sam"

Read this as: give the name customerName to the text "Sam".

PieceMeaning here
letIntroduce a name for a value.
customerNameThe name we chose. We can use it on the next line.
=Connect that name to the value on the right.
"Sam"A text value. The double quotes mark where the text begins and ends.

Programmers call a text value a string. This line gives the text a name; it does not display anything by itself. Microsoft's explanation of let.

3. Read the second line

printfn "%s" customerName

Read this as: display the text named customerName.

PieceMeaning here
printfnF#'s built-in function for printing a line of text.
"%s"A printing template. The marker %s means “put a string here.”
customerNameThe value to put into that template. It supplies "Sam".

The spaces separate the function name and what we pass to it. Keep the line in this order. The output is Sam, without the quotation marks or the %s marker. Microsoft's printing reference.

4. Check one small distinction

customerName uses the value we named earlier. "customerName", with quotes, is the literal text inside those quotes.

let customerName = "Sam"
printfn "%s" "customerName"
What does this changed program print?
